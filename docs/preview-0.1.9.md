# Voltura Worlds 0.1.9 — Sharper Pluto

Pluto now has clearer terrain across its far side and a repaired southern texture boundary.

- Removed the thin dark line near the bottom of the globe by replacing the reflected fill that copied the original image coverage edge.
- Reconstructed crisp far-side craters and icy terrain to bring their visual clarity closer to the encounter hemisphere, while retaining the original high-resolution heart region.
- Closed the longitude texture wrap and refreshed the native Pluto preview on the product site.

The far-side and southern details are an artistic reconstruction based on the broad New Horizons map, not new spacecraft measurements. Source attribution, the generation prompt and reproducible texture build inputs are included in the repository.

Run VolturaWorlds-Setup-0.1.9-win-x64.exe for Windows 11 x64. Existing settings, imported videos and startup preferences are retained. Version 0.1.8 can receive this release through its optional automatic updater. Versions 0.1.7 and earlier require the manual installer because of their older download-size limit.

The application and installer use the existing timestamped Voltura AB signing certificate. SHA256SUMS.txt accompanies the installer.
