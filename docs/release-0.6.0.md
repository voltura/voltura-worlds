# Voltura Worlds 0.6.0

Solar System Journey brings the library to **26 built-in Worlds**. Follow one continuous cinematic route through the Sun, Mercury, Venus, Earth, the Moon, Mars, Jupiter, Saturn, Uranus, Neptune and Pluto, then return to the Sun.

The camera eases between bodies against a shared starfield, reusing their existing textures, clouds, rings and solar effects. Arrival cards introduce each body and fade away before departure. Jupiter presents the Great Red Spot during its visit on every loop. Sizes and distances are artistically adjusted for the journey rather than shown to scale.

At normal speed, each stop lasts 25 seconds and each trip lasts 12 seconds: a 6 minute 47 second loop. Movement adjusts the pace continuously, and zero freezes the animation. Pause and automatic desktop pauses preserve progress. Arrival statistics default to enabled and have a separate saved preference from the individual scenes. Settings and portable desktop presets retain the journey configuration.

Choose Solar System Journey from the library, tray or **Voltura Worlds Solar System** desktop submenu. That submenu uses 13 commands, below its 16-command budget. Random pools continue to shuffle individual Worlds, leaving the journey uninterrupted.

The website includes a native recording of the Earth-to-Moon approach. The app, desktop-menu components and installer are signed and timestamped with Voltura AB's existing self-signed certificate. Run the installer to upgrade while retaining settings, presets and imported videos.
