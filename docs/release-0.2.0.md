# Voltura Worlds 0.2.0

The Worlds window title and tray icon tooltip now show the running app's version, read directly from its embedded version metadata.

This release also includes faster installer packaging and the corrected preset display counts from the changes following 0.1.11. All 22 Worlds, saved desktop presets, HDR output and per-display controls remain available.

To upgrade from 0.1.10 or earlier, exit Worlds and run the new installer once. Those older updaters require a separate checksum file that current releases no longer publish. Current automatic updates use GitHub's release-asset SHA-256 metadata and verify the publisher signature. Settings and imported videos are retained.

Download and run `VolturaWorlds-Setup-0.2.0-win-x64.exe`. The app and installer are timestamped and signed with Voltura's self-signed certificate.
