# Voltura Worlds 0.5.0

Tropical Island brings the library to 25 built-in Worlds: a sunlit tropical beach with a real-time 3D ocean, sloping sandy shore, changing reflections, refraction, generated foam and moving palms.

Wave arrivals vary, the wash drains gradually, foam disperses in patches and damp sand lingers between waves. Adjust wave speed, swell strength, water detail and palm breeze, with four palettes and optional audio reaction. The shoreline models gentle spilling surf analytically; it is not a full fluid simulation.

Tropical Island is available in the library, tray and desktop menus, Random rotation and saved presets. The desktop Off command now sits in the main Voltura Worlds menu to keep the visualization menu within Windows' command limit.

The app and installer are signed and timestamped with Voltura AB's self-signed certificate, which is not publicly trusted. Run the installer to upgrade while retaining settings, presets and imported videos.
