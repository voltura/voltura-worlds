# Smoke visual target

The user reaffirmed the Smoke concept on 2026-10-23: "If you get close to this
then we are good." This sets the target, not acceptance of the current renderer.
Reference: `concepts/smoke.png`; the user's attached desktop composition is the
authoritative reference when comparing results.

Judge native output by these visible properties:

- Distinct cyan and magenta plumes with saturated color, deep interior shadows,
  and rounded, overlapping folds that visibly occupy depth.
- Gold light concentrated in fine filaments and selected edges, rather than
  orange haze filling the volume.
- Multiple scales of structure: large curling masses, smaller rolling folds,
  and crisp wisps. Avoid repeated stripes, fabric, uniform noise and soft blobs.
- An asymmetric composition concentrated toward the center and right, leaving
  dark, quiet space on the left for desktop icons.
- Motion that preserves this structure while continuously evolving. A sharp
  still that dissolves into sheets or loses volume during playback fails.

Compare matched-size native stills and motion with the reference before asking
for another visual review. Label frozen-volume, offline and live-simulation
evidence separately. The existing native Smoke result has not met this target.

Keep installation and Windows desktop functionality in scope. Visual prototype
experiments alone do not justify replacing the last validated installer.
