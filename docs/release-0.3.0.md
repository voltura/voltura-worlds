# Voltura Worlds 0.3.0

Forest Water joins the library, bringing the total to 23 built-in Worlds. A
woodland canopy reflects through animated pond ripples while autumn leaves drift
and bob on the surface. Natural, Summer, Autumn and Overcast palettes, scene
adjustments and optional audio reaction are included.

Setup now offers optional desktop right-click menus for choosing Worlds on the
display where the menu is opened, alongside global playback and update controls.
The classic desktop menu and Windows 11 compact menu are separate opt-in choices.
Opening a menu does not start Worlds; when the app is closed, Open Voltura Worlds
remains available. The tray retains its Solar System submenu.

The installer runs for your Windows account. The optional Windows 11 compact menu
can request administrator approval to trust Voltura's public signing certificate.
Declining that step leaves the classic menu available. Silent updates preserve
menu preferences and never prompt for certificate trust or elevation.

The app, installer, shell DLL, menu identity package and certificate-trust helper
are signed and timestamped. Voltura's self-signed certificate is not publicly
trusted. Automatic updates retain GitHub release-asset checksum verification,
publisher-signature checks and product/version checks.

This release uses source review, compiler feedback and scripted packaging.
No automated tests or desktop/UI automation are used for release verification.
Menu behavior, certificate prompts and physical-display interactions are not
claimed as observed in this release run. Native website media demonstrates the
renderer; visual assessment remains with the user.
