Voltura Worlds 0.1.8 brings the Solar System to your desktop, with eleven new Worlds and 22 Worlds in total.

- Explore Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, Neptune, Moon, Pluto and Sun. Photographic scenes use bundled NASA and partner imagery; Venus, Uranus and Neptune use artistic procedural reconstructions. See the linked asset notices and scene documentation for sources and rendering limits.
- Choose Random Solar System to cycle through the eight planets, Moon, Pluto and Sun. Enable optional palette-matched body statistics, saved per display.
- Enjoy calm planetary rotation, shared catalog stars, scene-specific controls and optional local audio reaction. The previous metallic World is now called Plastic metal.
- The product page includes eight-second recordings from the native renderer for all eleven additions, alongside the existing Worlds, with an updated social preview.
- The updater supports larger downloads and a longer transfer deadline for future releases.

**Updating from 0.1.7 or earlier requires a manual download of this installer.** The bundled textures exceed those versions' 64 MiB automatic-update limit. Run VolturaWorlds-Setup-0.1.8-win-x64.exe for Windows 11 x64. No administrator access is required. Settings, imported videos and startup preferences are retained.

The application and installer use the existing timestamped Voltura AB signing certificate. It is self-signed and is not publicly trusted. SHA256SUMS.txt accompanies the installer.
